# CS Router

![CS Router](ui/banner.png)

claude-science 的供应商路由器。一个窗口、一个卡片列表、一个系统托盘、一个本地中继，
不依赖 claude.ai 登录即可使用第三方供应商推理。

## 构建

系统依赖：libwebkit2gtk-4.1-dev、build-essential；打包 deb 另需
libayatana-appindicator3-dev、librsvg2-dev。

```sh
cargo install tauri-cli --locked
cd src-tauri && cargo tauri build
```

## 架构

四个 Rust 模块加三个静态前端文件，无框架无构建步骤。

**存储** `~/.cs-router/config.json`，权限 0600。供应商字段含名称、备注、官网、接口地址、
认证字段、上游格式、密钥、默认模型、模型目录、角色映射。接口地址为空即官方登录条目，
可编辑可删除，清单清空后下次启动重新播种。

**虚拟登录** `oauth_forge.rs`：在 `~/.claude-science` 内以本地 `encryption.key` 经
HKDF 派生 AES-256-GCM 密钥，铸造一枚远期过期的 OAuth 令牌写入 `.oauth-tokens`，
令牌的 access_token 承载当前供应商密钥。网页端认证状态因此常为已登录，
与 claude.ai 网络完全解耦。

**本地中继** `relay.rs`：固定监听 127.0.0.1:39171。守护进程的接口地址指向它：
模型清单请求按登记目录以 claude-csswitch- 选择器标识应答，界面只显示登记模型；
消息请求读体重写模型名后转发真实供应商并回流流式响应。模型名解析三级：
选择器表命中、claude 家族名按角色映射、未配置角色回落默认模型。

**启动** 切换即生效：未运行则以新供应商拉起，运行中则停止后以新环境重启，
全部后台串行，界面乐观更新零等待。serve 以 `--detached` 启动，
环境继承经实测验证。对 `~/.claude-science` 的写入限于 `config.toml` 顶层
`default_model` 与虚拟登录令牌。

## 界面

卡片列表点切换按钮生效，当前项按钮呈使用中状态并常驻操作区；测试按钮实测模型
端点延迟；编辑页为全屏视图，基础信息、模型映射行编辑器、可折叠高级选项、底部
带语法高亮的 JSON 配置区，表单改动实时写穿 JSON，保存以 JSON 为准。
窗口按钮可切换应用级自建或系统模式，应用级模式下悬浮于两角。
字体拉丁用 Anthropic 衬线、中文 MiSans。

## 首次使用

添加供应商，选一个预填示例改名称与接口地址，填密钥，获取模型后选定默认模型，
按需配置角色映射，保存后点切换即启动服务并自动打开界面页。
